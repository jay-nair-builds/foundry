# Security policy

## Reporting a vulnerability

If you find a security problem, such as a script that runs unsafe code, an example that leaks a credential, or a dependency with a known vulnerability, please report it privately:

1. Open the **Security** tab of this repository.
2. Choose **Report a vulnerability**.

Please do not open a public issue for security problems. You can expect an acknowledgement within a week.

## Scope

This repository holds instructions, scripts and example files. It has no hosted service and stores no user data. Scripts read only the files they are given and make no network calls of their own.

## Supported versions

Only the latest release receives fixes.
